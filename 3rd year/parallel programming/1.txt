1. OpenMP — это API для многопоточного программирования в C, C++ и Fortran, использующее модель параллельного программирования с общей памятью.
2. Fork-Join — главный поток создаёт (fork) несколько потоков, затем они объединяются (join).

   Модель "Задачи" — позволяет разбивать работу на независимые задачи.

   Модель "Параллельные циклы" — автоматическое распределение итераций цикла между потоками.
3. C, C++, Fortran.
4. Состав в Visual Studio: компилятор (cl.exe с ключом /openmp), стандартная библиотека OpenMP, отладчик.
