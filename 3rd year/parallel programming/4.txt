1. Частные переменные нужны, чтобы каждый поток имел свою копию переменной. Это не противоречит модели общей памяти, так как OpenMP поддерживает гибридную модель.
2.Области видимости:
	shared — общая для всех потоков.
	private — создаётся копия для каждого потока.
	firstprivate — копируется начальное значение.
	lastprivate — сохраняет последнее значение.
3. 
int rank;
#pragma omp parallel
{
    rank = omp_get_thread_num();
    printf("Thread %d\n", rank);
}

Ошибка: потоки изменяют rank одновременно.
Решение: объявить rank как private(rank).
