решение методом деления пополам (дихотомии) с точностью ε=0.1.
Метод деления пополам требует, чтобы функция меняла знак на отрезке [a,b]. Вычислим значение функции на концах отрезка.
f(5) = cos(10)+5-5 = cos(10) = -0.839
f(6) = cos(12)+6-5 = cos(12)+1 = -0.536+1 = 0.464
функция f(x) принимает на концах отрезка значения разных знаков, значит уравнение f(x)=0 имеет на этом отрезке по крайней мере один корень

Первая итерация
найдем с. с = (5+6)/2=5.5
вычислим f(5.5) = cos(11)+5.5-5 = cos(11)+0.5 = -0.004+0.5 = 0.496 > 0
функция меняет знак на отрезке [5,5.5], поэтому новый интервал для поиска корня — [5,5.5].

Вторая итерация
найдем c. c = (5+5.5)/2=5.25
вычислим f(5.25) = cos(10.5)+5.25-5 = cos(10.5)+0.25 = -0.236+0.25 = 0.014 > 0
функция меняет знак на отрезке [5,5.25], поэтому новый интервал для поиска корня — [5,5.25].

Третья итерация
найдем c. c = (5+5.25)/2=5.125
вычислим f(5.125) = cos(10.25)+5.125-5 = cos(10.25)+0.125 = -0.335+0.125 = -0.21 > 0
функция меняет знак на отрезке [5.125,5.25], поэтому новый интервал для поиска корня — [5,5.25].
